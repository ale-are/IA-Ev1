## Descripción de la evaluación

Esta evaluación corresponde al análisis exploratorio de datos (EDA) y tratamiento de calidad de datos sobre un dataset de rendimiento académico.

El objetivo es realizar un diagnóstico inicial del dataset, identificando problemas de calidad como valores faltantes, registros duplicados, inconsistencias, valores atípicos y posteriormente aplicar estrategias de limpieza y transformación.

La evaluación incluye:

- Diagnóstico de calidad de datos.
- Análisis exploratorio de variables numéricas y categóricas.
- Estudio de relaciones entre variables y rendimiento académico.
- Tratamiento de datos mediante técnicas reproducibles.
- Implementación de transformaciones utilizando herramientas de Scikit-Learn.
- Generación de un dataset limpio final.
